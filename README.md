# yt-dlp

Runs yt-dlp to download a video, or only its audio, from a link: it takes a link and gives back a video or audio file. yt-dlp comes from the open-source project yt-dlp/yt-dlp, which AgentMesh did not write.

## What it does

- Download a video, or only its audio, from a link: Runs yt-dlp on a link and hands back a video or audio file.

## What it needs

Nothing from outside: no keys, accounts, other services, other code or other software.

## Where it came from

Pukkandan wrote it and publish it at https://github.com/yt-dlp/yt-dlp. This agent was made from commit c7fb478d21e9e59524befbe23f7801bb267fb880. AgentMesh did not write it; AgentMesh wrapped it so it can run as an agent. NOTICE.md says what AgentMesh added.
